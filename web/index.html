    Scope and interpretation

    This is a descriptive pileup summarizer. It does not call modifications from raw nanopore signals, identify differential methylation, phase reads, or make clinical decisions. The server-side Python agents in this repository are separate demonstration threshold evaluators.

    Input coordinates are 0-based and end-exclusive. Summaries are grouped by chromosome and modification code; a 5mC row and a 5hmC row may describe overlapping read coverage and must not be added together.

    Input definition: Official modkit pileup documentation. No data are sent to this website's server. Avoid public analysis of identifying specimen metadata.
